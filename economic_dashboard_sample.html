About the reference points

  • Fed 2% target — The Fed's explicitly stated longer-run inflation objective.
  • ~4% full-employment range — Same ~4% natural-rate reference applied at the state level.
  • ~2% trend growth — Widely-cited estimates of US long-run potential real GDP growth sit around 1.8-2.0%.
  • 0 = inversion threshold — Not an 'ideal' but a watched line: sustained negative values (inversion) have preceded recent recessions.
These are widely-cited reference points, not settled "ideal" values — reasonable economists dispute them, structural state rates differ from the national figure, and a number near a reference is not automatically "good" in isolation. Indicators without a defensible reference are shown without one rather than assigned an invented target.
